# remote-gfx-viewer

同じLAN上のPCにあるローカル画像を、**スマホのブラウザから閲覧**するための軽量な画像ビューアです。

- 📦 **依存ゼロ** — Python標準ライブラリだけで動作（追加インストール不要）
- 🖼️ **サムネイル一覧** — 画像をグリッド表示、タップで拡大
- 📁 **フォルダ階層の閲覧** — サブフォルダをたどって探せる
- 👆 **スワイプ操作** — 拡大表示中に左右スワイプで前後の画像へ／下スワイプで閉じる
- 🫥 **中央タップでUIトグル** — 画像中央をタップすると、評価・削除などのコントロールを半透明で表示/非表示
- 🦅 **Eagle 連携（任意）** — [Eagle](https://eagle.cool/) の**スマートフォルダ / すべて / 未分類**をスマホから閲覧、★評価・削除も可能
- ✨ **画像生成（任意）** — スマホから [AUTOMATIC1111 / Forge](https://github.com/AUTOMATIC1111/stable-diffusion-webui) に txt2img 生成を指示、結果を Eagle に保存
- 🔒 **パスワード認証（任意）** — `--password` でログイン必須に。出先公開時の必須装備
- 🌍 **出先からアクセス（任意）** — Cloudflare Tunnel でポート開放なしに公開 → [REMOTE.md](REMOTE.md)
- ⚡ **高速化（任意）** — [Pillow](https://pypi.org/project/Pillow/) を入れると軽量サムネイルを自動生成

## 必要なもの

- Python 3.8 以上（画像を置いているPC側）
- スマホとPCが**同じLAN（同じWi-Fi）**につながっていること

## 使い方

### 1. サーバーを起動（PC側）

```bash
python3 server.py /path/to/images
```

例:

```bash
# Windows の写真フォルダを公開
python3 server.py "C:\Users\you\Pictures"

# Mac / Linux
python3 server.py ~/Pictures
```

起動すると、アクセス先のURLがコンソールに表示されます:

```
  スマホのブラウザで以下を開いてください:
    http://192.168.1.23:8000/
```

### 2. スマホで開く

スマホのブラウザ（Safari / Chrome など）で、表示された
`http://<PCのIPアドレス>:8000/` を開くだけです。

## オプション

```bash
python3 server.py /path/to/images --port 8000 --host 0.0.0.0 --thumb-size 400
```

| オプション        | 既定値    | 説明                                                  |
| ----------------- | --------- | ----------------------------------------------------- |
| `directory`       | `.`       | 公開する画像フォルダ                                  |
| `--port` / `-p`   | `8000`    | 待ち受けポート                                        |
| `--host`          | `0.0.0.0` | 待ち受けアドレス（`0.0.0.0` でLAN全体に公開）         |
| `--thumb-size`    | `400`     | サムネイルの最大辺px（Pillow導入時のみ有効）          |

## 🦅 Eagle 連携（スマートフォルダをスマホで見る）

すでに [Eagle](https://eagle.cool/) を使っているなら、Eagle の**スマートフォルダ**を
スマホのブラウザから閲覧できます。

### 使い方

1. PC で **Eagle アプリを起動**しておく（Eagle のローカル API を利用します）
2. `--eagle` を付けて起動する:

   ```bash
   python3 server.py --eagle
   ```

3. スマホで `http://<PCのIP>:8000/` を開くと、トップに以下が表示されます。
   タップすると中の画像がサムネイル表示されます。

   - 🗂️ **すべて** … ライブラリ内の全画像
   - 📭 **未分類** … どのフォルダにも属していない画像
   - 🧩 **スマートフォルダ未該当** … どのスマートフォルダの条件にも当てはまらない画像
     （Eagle 本体だけでは作れない、本ツール独自の集計ビュー）
   - 🔍 **各スマートフォルダ** … 設定した条件に合致する画像

ファイルフォルダの閲覧と Eagle 連携は併用もできます（その場合トップは Eagle 一覧になります）:

```bash
python3 server.py ~/Pictures --eagle
```

API の URL を変えたい場合:

```bash
python3 server.py --eagle --eagle-api http://localhost:41595
```

### スマホから編集する（★評価・削除）

`--allow-edit` を付けて起動すると、拡大表示中に次の操作ができます（Eagle に反映されます）。

```bash
python3 server.py --eagle --allow-edit
```

拡大表示中に**画像の中央をタップ**すると、上下のコントロール（評価・削除）が
半透明で表示されます。もう一度タップすると隠れて画像だけを見られます。

- ⭐ **★評価の変更 / お気に入り登録** … 下部の★をタップして 0〜5 を設定。
  **★5＝お気に入り**として使えます（同じ★を再タップで解除）。
  ※ Eagle には専用の「お気に入り」フラグが無いため、★評価で表現しています。
- 🗑 **削除** … 「削除」ボタン → 確認の上で Eagle の**ゴミ箱へ移動**します
  （完全削除ではなく、Eagle 側で元に戻せます）。

> ⚠️ **安全のため、編集は `--allow-edit` を付けたときだけ有効**です（既定は閲覧専用）。
> このツールは認証が無いため、`--allow-edit` を付けると**同じLAN上の誰でも
> ★変更・削除ができる**点にご注意ください。信頼できるネットワークでのみ使ってください。

### 仕組みと制約（重要）

Eagle のスマートフォルダは「実体フォルダ」ではなく「**保存された検索条件**」です。
本ツールは Eagle のローカル API（既定 `http://localhost:41595`）から条件を取得し、
全アイテムに対して条件を評価して中身を再現します。

対応している条件（**方式A**）:

- ✅ 名前 / タグ / メモ / URL / 拡張子（種類） / 評価（★） / 幅・高さ・サイズ / 向き / フォルダ

未対応の条件:

- ⚠️ **色** / **日付** などはまだ評価しません。これらを含むスマートフォルダは
  「条件一部のみ対応」と表示され、**Eagle 本体より多くの画像が表示される**ことがあります。

その他の注意:

- Eagle アプリが**起動している**必要があります（API が Eagle のプロセスのため）。
  起動していないときは接続案内のページが表示されます。
- 画像以外（動画など）は一覧から除外されます。

## ✨ スマホから画像生成（AUTOMATIC1111 / Forge）

PC で動いている stable-diffusion-webui（AUTOMATIC1111 / Forge）に、
スマホから txt2img の生成を指示できます。

### 使い方

1. webui を **API 有効**で起動する（起動引数に `--api` を付ける）

   ```bash
   ./webui.sh --api          # Mac / Linux
   webui-user.bat            # Windows は COMMANDLINE_ARGS に --api を追加
   ```

2. `remote-gfx-viewer` を `--sd` 付きで起動する

   ```bash
   python3 server.py --eagle --sd --password "長めのパスワード"
   ```

3. スマホで開き、右上の **「✨ 生成」** から生成画面へ。
   プロンプトを入れて「生成する」を押すと、進捗バーののち結果が表示されます。

### 生成画面でできること

- **プロンプト / ネガティブプロンプト**
- **サイズ（幅・高さ）/ 枚数**（SDXL 既定 1024×1024）
- **詳細設定**: Steps / CFG / Seed / サンプラー（webui から自動取得）
- **Eagle に保存**: チェックを入れると生成結果を Eagle ライブラリへ取り込み（`SDXL` タグ付き）

### オプション

```bash
python3 server.py --sd --sd-api http://127.0.0.1:7860
```

| オプション   | 既定値                  | 説明                          |
| ------------ | ----------------------- | ----------------------------- |
| `--sd`       | 無効                    | 生成機能を有効化              |
| `--sd-api`   | `http://127.0.0.1:7860` | webui の API URL              |

> 補足: 生成には時間がかかるため、進捗は webui の `/sdapi/v1/progress` を
> ポーリングして表示します。出先から使う場合は **`--password` の併用を推奨**します。

## 🔒 パスワード認証

`--password` を付けると、アクセス時にログイン画面が出てパスワードが必須になります。

```bash
python3 server.py --eagle --password "長めのパスワード"
```

- 環境変数でも指定できます: `RGV_PASSWORD="..." python3 server.py --eagle`
- ログイン状態はクッキー（30日）で保持され、右上の「ログアウト」で解除できます。
- LAN内だけで使う場合は省略可ですが、**出先に公開するときは必須**です。

## 🌍 出先（外出先）から見る

ルーターのポート開放なしに、Cloudflare Tunnel で公開できます。
手順は **[REMOTE.md](REMOTE.md)** にまとめています。

```bash
# 1) 認証付きでアプリを起動
python3 server.py --eagle --allow-edit --password "長めのパスワード"
# 2) 別ターミナルでトンネルを張る（公開URLが発行される）
cloudflared tunnel --url http://localhost:8000
```

> ⚠️ 公開URLは知られれば誰でもアクセスを試せます。**必ず `--password` を併用**してください。

## サムネイル生成を速くする（任意）

画像が多い・サイズが大きい場合は Pillow を入れると、
縮小済みの軽量サムネイルを配信してスマホでの読み込みが速くなります。

```bash
pip install Pillow
```

未導入でも動作します（その場合は元画像をブラウザ側で縮小表示します）。

## 対応している画像形式

`.jpg` `.jpeg` `.png` `.gif` `.webp` `.bmp` `.tif` `.tiff` `.heic` `.avif`

（`.heic` / `.avif` のサムネイル生成にはPillowの対応ビルドが必要な場合があります）

## セキュリティについて

- このサーバーは**LAN内向け**の簡易ツールです。認証はありません。
  同じネットワーク上の人なら誰でも閲覧できます。
- 公開フォルダの**外**へはアクセスできないよう、パス・トラバーサル対策をしています。
- インターネットへ直接公開する用途には向きません。外出先から見たい場合は
  VPN やトンネリングツール越しに使ってください。

### Windows でつながらないときは

Windows のファイアウォールでブロックされている可能性があります。
初回起動時に表示される許可ダイアログで「プライベートネットワーク」を許可するか、
指定したポート（既定 8000）の受信を許可してください。
